# cses-solutions

Soluções para problemas do [CSES Problem Set](https://cses.fi/problemset/), implementadas em Java.

## Estrutura

cses-solutions/
└── graph-algorithms/
└── ShortestRoutesI.java

## Problemas resolvidos

| # | Problema | Categoria | Algoritmo |
|---|----------|-----------|-----------|
| 1671 | [Shortest Routes I](https://cses.fi/problemset/task/1671) | Graph Algorithms | Dijkstra |

## Como executar localmente

```bash
javac ShortestRoutesI.java
java Main < input.txt
```

Onde `input.txt` contém o caso de teste no formato esperado pelo problema.
